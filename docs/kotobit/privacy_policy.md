# Kotobit プライバシーポリシー

Natsuki Idota（以下「提供者」といいます。）は、iOSアプリ「Kotobit（コトビット）」（以下「本アプリ」といいます。）における、利用者の情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」といいます。）を定めます。

## 1. 収集しない情報

本アプリには、アカウント登録やログインの機能はありません。
提供者が、利用者の氏名、メールアドレス、電話番号、住所などの個人情報を収集することはありません。

## 2. 利用者が登録した言葉

利用者が本アプリに登録した言葉、読み方、意味は、利用者の端末と、利用者自身のiCloudにのみ保存されます。
iCloudへの保存は、端末でiCloudにサインインしている場合に、利用者の端末間でデータを同期するために行われます。
提供者がこれらのデータを閲覧、収集することはできません。

## 3. 自動的に収集される情報

本アプリは、品質の改善と不具合の調査のため、Google LLCが提供する以下のサービスを利用しています。これらのサービスにより、次の情報が自動的に収集されることがあります。

| サービス | 収集される情報の例 | 目的 |
|---|---|---|
| Firebase Analytics | アプリの利用状況（画面の表示、起動回数など）、端末の機種、OSのバージョン、アプリのバージョン、おおよその地域、アプリごとに割り当てられる識別子 | 利用状況を把握し、本アプリを改善するため |
| Firebase Crashlytics | アプリが強制終了したときの記録、端末の機種、OSのバージョン、アプリのバージョン | 不具合の原因を調査し、修正するため |
| Firebase Performance Monitoring | アプリの起動時間、通信にかかった時間などの動作の記録、端末の機種、OSのバージョン | 動作の速さを把握し、改善するため |

これらの情報には、利用者個人を特定できる情報は含まれません。
また、本アプリは広告を表示せず、広告目的で情報を利用したり、利用者を追跡したりすることはありません。

Googleによる情報の取り扱いについては、以下をご確認ください。

- [Firebase のプライバシーとセキュリティ](https://firebase.google.com/support/privacy)
- [Google プライバシーポリシー](https://policies.google.com/privacy)

## 4. 第三者への提供

提供者は、法令に基づく場合を除き、収集した情報を第三者に提供しません。

## 5. 本ポリシーの変更

提供者は、必要に応じて本ポリシーを変更することがあります。
変更後の本ポリシーは、このページに掲載した時点から効力を生じます。
